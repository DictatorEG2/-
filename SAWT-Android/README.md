# صَوْت | SAWT

مساعد صوتي عربي للتحكم في هاتف Android بالأوامر الصوتية (فصحى ومصرية)، مبني بـ Kotlin وJetpack Compose، ويعتمد على `AccessibilityService` في التحكم الفعلي بالشاشة.

## خطوات التشغيل (ابدأ من هنا)

1. ثبّت **Android Studio Koala (2024.1.1) أو أحدث** مع **JDK 17** و**Android SDK 34**.
2. افتح المجلد `SAWT-Android` من Android Studio (Open) ودع **Gradle Sync** يعمل (يحتاج إنترنت لتنزيل المكتبات أول مرة).
3. وصّل هاتفك (Infinix Smart 8 / Android 13) بتفعيل **خيارات المطور ← تصحيح USB**، ثم اضغط **Run ▶**.
4. داخل التطبيق: شاشة **الأذونات** ← اسمح بالميكروفون ← **فعّل خدمة إمكانية الوصول** لصَوْت من إعدادات النظام.
5. ثبّت حزمة العربية للتعرف دون إنترنت: إعدادات Google ← الصوت ← التعرف على الكلام دون اتصال ← العربية.
6. اضغط الزر الكبير في الصفحة الرئيسية وقل: «يا صَوْت افتح الرسائل».

من سطر الأوامر (بعد توليد الـ wrapper، راجع `BUILD.md`):
```
./gradlew testDebugUnitTest   # اختبارات الوحدات
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk
```

## حالة المشروع — اقرأ هذا قبل الاعتماد عليه

- **هذه النسخة المعدّلة لم يُنفَّذ لها بناء Gradle أو اختبار على جهاز** في بيئة التعديل؛ لذلك لا يوجد APK مثبت الصلاحية ولا ادعاء بنجاح البناء. اختبارات الوحدات الأصلية مكتوبة ولم تُنفَّذ هنا. تفاصيل الفحوصات في `TESTING.md`.
- احتمال وجود أخطاء بناء بسيطة (استيراد ناقص أو توقيع دالة) وارد عند أول مزامنة؛ تُصلَح عادةً في دقائق.
- الوظائف مكتوبة بكود حقيقي لا نماذج وهمية، لكن سلوكها على الجهاز (خصوصًا بدء الميكروفون من الخلفية وأداء التعرف) **يجب اختباره على الجهاز** حسب قائمة `TESTING.md`.
- القيود التقنية لكل وظيفة في `LIMITATIONS.md`.

## معيار Dictator وCI
تُطبَّق ثوابت Dictator في `DICTATOR_STANDARDS.md` على كل تعديل. يشغّل GitHub Actions اختبارات الوحدات وبناء Debug عند الدفع أو فتح Pull Request. لا يعني نجاح CI وحده اكتمال اختبار الجهاز الفعلي.

## التحديثات التلقائية
يفحص التطبيق مستودع `DictatorEG2/-` عند التشغيل بعد مرور 24 ساعة على آخر فحص ناجح (ويعيد المحاولة بعد ساعة عند الفشل)، ويحفظ بيانات الإصدار ويعرض إشعارًا عند وجود إصدار أحدث. لا ينزّل ولا يثبت تلقائيًا؛ يبدأ المستخدم التنزيل من داخل التطبيق ويوافق على التثبيت في Android. راجع `UPDATE_SETUP.md` لإعداد Release وتوقيع APK.
