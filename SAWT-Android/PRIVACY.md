# سياسة الخصوصية — صَوْت | SAWT

هذه السياسة تصف سلوك الكود الحالي فعلًا. إن عدّلت الكود (مثلًا أضفت مكتبة تستخدم الشبكة) فحدّثها.

## ملخص
- لا حساب إجباري، ولا إعلانات، ولا تحليلات، ولا SDK تتبع.
- يطلب التطبيق صلاحية `INTERNET` **لغرض واحد محدد**: قراءة بيانات الإصدار العام من GitHub وتنزيل ملف APK الذي ينشره المطوّر.
- لا توجد تحليلات أو إعلانات أو SDK تتبع أو رفع لسجل الأوامر أو محتوى الشاشة أو التسجيلات الصوتية.
- يبدأ فحص التحديث تلقائيًا بعد مرور 24 ساعة على آخر فحص ناجح عند فتح التطبيق، ويعيد المحاولة بعد ساعة إذا فشل الفحص، ويمكن الفحص يدويًا من إعدادات الصوت. لا يحدث اتصال التحديث إلا مع `api.github.com` وروابط تنزيل `github.com`.
- لا يثبت التطبيق التحديث بصمت؛ Android يعرض شاشة التثبيت ويطلب موافقة المستخدم. وقد يطلب السماح لصَوْت بتثبيت حزم من هذا المصدر.
- النسخ الاحتياطي التلقائي معطّل (`allowBackup=false`).

## الصوت
- لا يبدأ الاستماع إلا بتفعيل المستخدم (زر التطبيق أو الزر العائم).
- أثناء الاستماع: إشعار دائم بزر «إيقاف» فوري، والزر العائم يتلوّن بالقرمزي.
- **لا يحفظ التطبيق أي تسجيل صوتي ولا يسجّل المكالمات.** لا يستخدم `AudioRecord` ولا `MediaRecorder`. تتم معالجة الصوت بواسطة محرك التعرف في نظام الهاتف (`SpeechRecognizer`).
- يتوقف الاستماع تلقائيًا بعد فترة خمول (الافتراضي 90 ثانية، قابل للتعديل).

## التعرف المحلي مقابل الإنترنت
| الوضع | ما يحدث |
|---|---|
| **محلي (الافتراضي)** على Android 13+ | يُستخدم محرك التعرف على الجهاز (`createOnDeviceSpeechRecognizer`). لا يُرسَل الصوت إلى خوادم. إن لم تتوفر حزمة العربية المحلية يتوقف التعرف برسالة توضح السبب. |
| محلي على Android 12 وأقدم | يُطلَب التعرف المحلي كـ**تفضيل** (`EXTRA_PREFER_OFFLINE`) **بلا ضمان**. |
| وضع الاتصال (اختياري، يفعّله المستخدم) | قد تستخدم خدمة التعرف في الهاتف (Google) الإنترنت وقد يُرسَل الصوت إلى مزوّدها وفق سياسته هو. اتصال صَوْت نفسه يظل مقتصرًا على فحص GitHub وتنزيل التحديثات. |

## خدمة إمكانية الوصول
- تُفعَّل يدويًا من إعدادات النظام بعد إفصاح واضح داخل التطبيق.
- تُستخدم فقط لتنفيذ ما يطلبه المستخدم. لا يُخزَّن محتوى الشاشة ولا يُرسَل.
- حقول كلمات المرور تُتجاوز: لا تُقرأ ولا تُرقَّم ولا يُكتب فيها.
- لا تُستخدم لأي غرض آخر.

## البيانات المخزَّنة محليًا
| البيانات | أين | ملاحظات |
|---|---|---|
| سجل الأوامر | Room (`sawt.db`) | قابل للتعطيل والمسح. يُحجب النص المكتوب بالصوت وأرقام الهواتف. حد أقصى 500 سجل. |
| الاختصارات | Room | عباراتك فقط. |
| الإعدادات | SharedPreferences | تفضيلات الواجهة والصوت وموضع الزر. |
| سجل أخطاء تقني | `files/logs/errors.log` | حتى 100 كيلوبايت؛ نوع الخطأ فقط، دون صوت أو نص منطوق أو محتوى شاشة. |

## الأذونات وأسبابها
| الإذن | السبب |
|---|---|
| `RECORD_AUDIO` | سماع الأوامر |
| `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_MICROPHONE` | إبقاء الاستماع ظاهرًا بإشعار دائم |
| `POST_NOTIFICATIONS` | إظهار الإشعار على Android 13+ |
| `VIBRATE` | اهتزاز اختياري عند نجاح الأمر |
| `INTERNET` | فحص إصدار GitHub وتنزيل APK فقط؛ لا يُستخدم لإرسال بيانات المستخدم |
| `REQUEST_INSTALL_PACKAGES` | فتح مثبت Android بعد تنزيل تحديث، مع موافقة المستخدم |
| `WRITE_SETTINGS` (اختياري) | أوامر الإضاءة فقط، ويمنحه المستخدم يدويًا |
| خدمة إمكانية الوصول | التحكم بالشاشة بطلب المستخدم |

**لا يُطلب:** جهات الاتصال، الوصول العام للملفات والصور، الموقع، الكاميرا، قراءة الرسائل، إجراء المكالمات (`CALL_PHONE`).

## الأوامر الحساسة
- الاتصال لا يتم إلا بعد «نعم»، ويقتصر على فتح شاشة الاتصال.
- لا يرسل التطبيق رسائل ولا ينفّذ مكالمات نيابةً عن المستخدم.

## التحديثات
- يقرأ التطبيق بيانات الإصدار العام من GitHub Releases للمستودع المحدد في `UpdateConfig.kt`.
- ينزّل ملف APK فقط من رابط HTTPS يبدأ بـ `github.com`، عبر Android DownloadManager.
- بعد اكتمال التنزيل يظهر إشعار لفتح مثبت Android. لا توجد آلية تثبيت صامت.
- لا يُرسل التطبيق حسابًا أو سجلًا أو صوتًا أو أوامر إلى GitHub؛ طلب الإصدار والتنزيل يكشفان عنوان IP وبيانات الاتصال المعتادة لخوادم GitHub وفق سياسة GitHub.
- يجب أن يُوقّع كل إصدار بمفتاح التوقيع نفسه، وإلا سيرفض Android التحديث.

## روابط خارجية
زر «قناتنا على تيليجرام» يفتح الرابط في تطبيق تيليجرام أو المتصفح؛ وعندها تنطبق سياسة تلك الجهة.
