# الأوامر المدعومة

كل الأوامر تعمل مع بداية اختيارية بـ «يا صَوْت». الترتيب غير مهم في الأوامر البسيطة («الصوت ارفع» = «ارفع الصوت»)، ويُتجاهل الحشو («لو سمحت»، «ممكن»، «عايز»…).

## كيف يفهم المحلل
1. **التطبيع**: إزالة التشكيل والتطويل، توحيد الألف (أ إ آ ← ا) والياء (ى ← ي) والتاء المربوطة (ة ← ه)، وتحويل الأرقام الهندية.
2. **إزالة كلمة التنبيه** («يا صوت») والحشو.
3. **أوامر المعاملات** تُحلَّل بالبنية: كتابة، يوتيوب، واتساب، اتصال، ضغط.
4. **الأوامر البسيطة** تُطابَق كمجموعة كلمات؛ يفوز التطابق الأطول، وتُستبعد كلمات متعارضة (مثل «ارجع» لا تُطابَق إن وُجدت «الرئيسية»).
5. **فتح تطبيق**: فعل فتح + اسم، يُحلّ عبر أسماء شائعة (الفيس، واتس…) ثم باسم التطبيق المثبّت.
6. **اختصارات المستخدم** لها الأولوية على الأوامر المدمجة.

## الجدول
| الأمر | أمثلة | التنفيذ |
|---|---|---|
| **الرسائل (الاختصار الأساسي)** | «يا صَوْت افتح الرسائل»، «ادخل على الرسائل»، «شغّل تطبيق الرسائل»، «هات الرسائل» | يفتح تطبيق SMS الافتراضي |
| رجوع | ارجع، رجوع، للخلف | `GLOBAL_ACTION_BACK` |
| الرئيسية | ارجع للرئيسية | `GLOBAL_ACTION_HOME` |
| الأخيرة | افتح التطبيقات الأخيرة | `GLOBAL_ACTION_RECENTS` |
| فتح تطبيق | افتح فيسبوك، شغل الفيس، ادخل على الفيس، افتح واتساب | Intent إطلاق |
| تمرير | انزل، تحت، مرر لأسفل / اطلع، فوق، مرر لأعلى | `ACTION_SCROLL_*` ثم إيماءة سحب احتياطية |
| الصوت | ارفع الصوت، علّي الصوت، وطّي الصوت، اكتم الصوت | `AudioManager` |
| الإضاءة | زوّد الإضاءة، قلل الإضاءة | `Settings.System` (يتطلب سماحًا من المستخدم) |
| أرقام العناصر | أظهر الأرقام، أخفِ الأرقام | شارات فوق العناصر القابلة للضغط |
| ضغط بالرقم | اضغط على العنصر رقم 3، رقم ثلاثة | `ACTION_CLICK` أو نقرة إيماءة |
| ضغط بالاسم | اضغط على إرسال | بحث بنص العنصر |
| كتابة | اكتب مرحبا بك | `ACTION_SET_TEXT` في الحقل النشط |
| كتابة لاحقة | اكتب النص التالي ← ثم قل النص | الجملة التالية (12 ثانية) تُكتب كلها |
| قراءة الشاشة | اقرأ الشاشة | استخراج نص ظاهر + TTS |
| الإعدادات | افتح الإعدادات | `Settings.ACTION_SETTINGS` |
| لقطة شاشة | التقط لقطة شاشة | `GLOBAL_ACTION_TAKE_SCREENSHOT` (Android 9+) |
| يوتيوب | ابحث في يوتيوب عن … | صفحة نتائج البحث |
| محادثة واتساب | افتح محادثة واتساب مع الرقم 01001234567 | `wa.me` (الرقم المصري يُحوَّل لصيغة دولية) |
| اتصال | اتصل بالرقم … | **يتطلب «نعم»**؛ يفتح شاشة الاتصال فقط |
| إيقاف | وقف الاستماع، اسكت | يوقف الجلسة |
| تأكيد/إلغاء | نعم، تمام / إلغاء، لا | لأمر حساس معلّق فقط |

## توسعة القاموس
- مرادفات أمر بسيط: أضف عبارة إلى `phrases` في القاعدة داخل `RULES`.
- اسم تطبيق جديد: أضف إلى `ALIASES` في `AppResolver`.
- عبارات خاصة بك دون تعديل الكود: شاشة **الاختصارات**.
